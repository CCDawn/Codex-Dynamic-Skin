# Codex Dynamic Skin v1.7.3

**English** · [中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.7.3/docs/releases/v1.7.3.md)

This is a brand-unification release: the macOS app name, notification wording, and shortcuts switch to this repository's brand ("Codex 动态壁纸 / Codex Dynamic Skin"), matching the Windows side. Functionality is identical to v1.7.2 — no behavior changes.

## Changes

- **App rename (macOS)**: the menu-bar app's display name changes from "Codex Dream Skin" to "Codex Dynamic Skin"; the DMG volume name follows. **Upgraders from v1.7.2 and earlier**: the old and new apps share the same internal identity but not the name — after installing, drag the old "Codex Dream Skin.app" to the trash; login items and settings follow the new build automatically.
- **Wording (macOS)**: user-facing strings that referred to the official client as "ChatGPT" now say "Codex"; leftover "ChatGPT Dream Skin" notification titles are now "Codex 动态壁纸".
- **Shortcuts (macOS)**: the five `.command` launchers (repository and installer-created) are renamed; the uninstall cleanup covers both generations, so shortcuts created by older builds are also removed on uninstall.
- **Docs (Windows)**: the install and theme-management guides still named the old shortcut brand; they now match the actual "Codex 动态壁纸".

## What stays the same

- Internal identities (bundle id, URL scheme, state directories, DMG asset filename) are unchanged — settings, login items, and community theme sources survive the upgrade untouched.
- The standalone `CodexDreamSkinManager.exe` only bumps its version; its embedded runtime is identical to v1.7.2.

## Upgrading

- Users on v1.6.x / v1.7.x can run the new installer in place; saved themes, images, and video wallpapers are preserved.
- macOS users should delete the old "Codex Dream Skin.app" after upgrading (see above); desktop shortcuts are replaced with the new names automatically.
- The standalone (portable) manager is available as `CodexDreamSkinManager.exe` on the Releases page.
