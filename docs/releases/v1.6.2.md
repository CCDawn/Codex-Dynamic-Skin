## Codex 动态壁纸 v1.6.2

远程桌面性能优化版。

### 本次新增

- **RDP 会话自动降级为静态帧**：远程桌面（RDP）会话经 WARP 软件合成渲染，拿不到物理 GPU，全窗口视频壁纸会持续消耗 CPU（Chromium 的"GPU"进程实际在用 CPU 合成）并淹没远程画面流，表现为整机体感掉帧。现在启动皮肤时检测当前会话（`WTSQuerySessionInformation`），远程会话中视频主题改为解码单帧海报作为静态壁纸，捕帧后立即回收视频元素与 Blob 内存；前景半透明沉浸效果保持不变。回到本地控制台会话后，托盘每分钟一次的会话检查会自动重新应用并恢复视频播放（气泡提示）。
- 新增本地化键 `SessionTransportPoster` / `SessionTransportVideo`（中英双语）。

### 技术说明

- 主题媒体新增 `media.transport` 字段：`"poster"` 时渲染器走"传输 → 捕帧 → 静态 art → 回收"管线，任何捕帧失败都会回退为正常视频播放，不会出现无壁纸状态。
- 该字段由 Windows 启动脚本按会话状态通过环境变量 `CODEX_DREAM_SKIN_POSTER` 注入，payload 修订号随之区分；macOS 不受影响。

### 包含 v1.6.1 全部变更

- 视频壁纸透进前景内容区；恢复页面内操作进度浮层；修复 macOS 发版测试断言。
