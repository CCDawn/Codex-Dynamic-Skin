# Codex 动态壁纸 v1.8.4

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.4/docs/releases/v1.8.4-en.md)

这一版修复场景壁纸导致的升级卡死：活动主题是 Wallpaper Engine 场景（含旧版本声明的遗留形态）时，安装与启动不再误把它当图片校验而失败。

## 变更

- **场景主题不再卡死安装与启动**：当活动主题是 Wallpaper Engine 场景（`scene.pkg`，包括旧版本声明的遗留形态）时，安装与启动路径此前把它误当图片做校验而失败，导致安装回滚、无法启动。现在按场景媒体正确读取并容忍这类主题，升级不再被旧场景主题卡死。
- **启动校验失败降级为警告**：启动时的主题校验失败不再中止启动，降级为警告并保留当前注入状态。

## 不变的部分

- 注入方式仍是仅绑 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名。
- 本版无选择器与兼容性变化，macOS 侧无功能变化。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。

## 升级与使用

- 已安装 v1.8.0 – v1.8.3 的用户可直接运行新安装包原地升级。
- 升级后若主题显示异常，在管理器里重新应用一次即可恢复。
