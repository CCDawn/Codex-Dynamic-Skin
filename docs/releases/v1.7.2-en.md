# Codex Dynamic Skin v1.7.2

**English** · [中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.7.2/docs/releases/v1.7.2.md)

This release introduces the selector compatibility profile: when a Codex app update shifts the DOM and breaks the skin, a signed profile published by the maintainer repairs it on the next client start — no installer release required.

## New

- **Selector compatibility profile (macOS / Windows)**: the skin anchors on selectors that locate Codex UI elements, and upstream app updates can invalidate them. Starting with this version the client asynchronously fetches an ed25519-signed compatibility profile (served from this repository's GitHub RAW) at startup. After a fail-closed validation chain it may only replace the locator strings of selectors already registered in the built-in contract; any failed step discards the whole profile and falls back to the built-in selectors, so skinning is never blocked. The fetch is bounded (5 s timeout, 64 KiB body cap) and never introduces executable content. Set `DREAMSKIN_COMPAT_PROFILE=0` to disable the mechanism entirely. Maintainer runbook: `docs/compat-profile-runbook.md`.
- **Self-hosted distribution**: the profile is served from the same GitHub repository as the releases; no third-party service is involved.

## Fixes and improvements

- **macOS update guidance (macOS)**: "Check for updates" and the update notification previously sent users to the upstream repository; they now point at this repository's Releases page.
- **Manager EXE size (Windows)**: the standalone `CodexDreamSkinManager.exe` no longer embeds the native theme manager it never runs, shrinking from ~172 MiB to ~102 MiB with no feature change; the wallpaper library, video preview, and Wallpaper Engine integration are intact.
- **Bundled preset links (macOS / Windows)**: the built-in theme's promo link now points at this repository.

## Upgrading

- Users on v1.6.x / v1.7.x can run the new installer in place; saved themes, images, and video wallpapers are preserved.
- The compatibility profile is on by default and needs no configuration; set `DREAMSKIN_COMPAT_PROFILE=0` before launching Codex to opt out.
- The standalone (portable) manager is available as `CodexDreamSkinManager.exe` on the Releases page.

## Internals

- The seven-step fail-closed chain (fixed origin, bounded read, shape, revision monotonicity, signature, freshness, key intersection) lives in one shared module (`tools/compat-profile-client.mjs`) staged to both platforms by the asset sync tool, eliminating cross-platform drift.
- The maintainer-side signing toolchain (`tools/generate-compat-keypair.mjs`, `tools/build-compat-profile.mjs`) and 28 dedicated test cases are covered by CI.
- The manager embed manifest, release fixtures, and the macOS/Windows byte-identity assertions all cover the new shared module, preventing another "missing file on a clean machine" release incident.
- Sync-chain source files are now pinned to LF in `.gitattributes`, fixing spurious sync failures on Windows CI caused by line-ending checkout differences.
