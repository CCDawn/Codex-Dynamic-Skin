# Codex Dynamic Skin v1.8.0

**English** · [中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.0/docs/releases/v1.8.0.md)

This release restores compatibility with the November 2026 Codex updates (26.1103 / 26.1106), makes wallpaper-only mode the default, and adds a panel-transparency slider to the Windows manager alongside high-DPI layout fixes.

## Changes

- **Codex 26.1103 / 26.1106 compatibility (Windows)**: three breakages fixed — the renderer CSP no longer allows loopback media streams, so injection now lifts the policy before attach and reloads an already-loaded page once; MSE segment assembly is rejected by the new build, so the renderer falls back to direct progressive stream playback; and the official CSS Module class names dropped their underscores (main content, composer, gradient decoration layers), so the selector contract now uses substring matches with recorded on-device evidence. Themes and live wallpapers broken by the Codex update work again.
- **Wallpaper-only mode is now the default**: only surfaces are made transparent to reveal the wallpaper; colors, fonts, and layout stay 100% official. Full skin mode remains available. macOS Studio custom themes still default to the full skin; pass `--ui wallpaper-only` for the exclusive mode.
- **Panel-transparency slider (Windows manager)**: the frosted-glass transparency of conversation cards (composer, hint banners) is independently adjustable and composes with the wallpaper-intensity slider. The gradient "fog bands" above and below the conversation area and the square corner spikes behind the rounded composer card are also gone.
- **No bundled sample portrait by default**: the default theme is now fully blank — with no wallpaper selected the UI stays exactly official, and stream themes show Codex's own loading page at startup. The previous sample art survives only as the installer's public preset.
- **Manager UI fixes (Windows)**: per-monitor DPI (PerMonitorV2) aware scaling and layout; Wallpaper Engine scene streams are now served by the manager itself instead of relying on a debug port.

## Unchanged

- Injection still uses a loopback-only CDP connection on `127.0.0.1`; official installers and signatures are never modified, and the official look can be restored at any time.
- Local theme, image, and video wallpaper data directories are unchanged and survive the upgrade.

## Upgrading

- Users on v1.6.x / v1.7.x can run the new installer directly as an in-place upgrade.
- If a theme broke after updating Codex to 26.1103 / 26.1106, install this version and click "Start / Re-apply" in the tray or manager — no Codex reinstall needed.
- The portable manager is available as `CodexDreamSkinManager.exe` from the Releases page.
