# Codex 动态壁纸 v1.8.6
**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.6/docs/releases/v1.8.6-en.md)

这一版修的是启动链路：Codex 26.11xx 上点"启动"会报 Dream Skin verification failed，窗口被关掉。现在能正常起来。

## 变更

- **认下 Home 与对话页的 L0 结构**：Codex 26.11xx 在这两个页面不再输出 header tint 标记，结构判定随之从 L1 降到 L0。原来的验证只接受"L0 + 设置页"和"L1 完整结构"两种组合，Home 与对话页正好落在中间，于是每次启动都被判失败。现在只要侧边栏和主区域确实可见，L0 的 Home、对话、设置页都算通过；缺少侧边栏或主区域的页面仍然判定失败。
- **修正一像素的边界误判**：区域位置取整后右边界和下边界可能与视口正好差 1 像素，被当成越界，进而让输入框可见性判定失败。现在右、下边界允许 1 像素舍入误差，左、上边界仍然严格。
- **Windows 与 macOS 同步**：两端使用同一套 L0 结构判定，不会出现只有一端修好的情况。

## 不变的部分

- 注入方式仍是仅绑 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名，随时可恢复官方外观。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。
- 面板透明度滑杆、壁纸浓度滑杆与场景壁纸的行为未改动。

## 升级与使用

- 已安装 v1.8.x 的用户可直接运行新安装包原地升级。
- 升级后如果窗口仍是旧外观，重启一次 Codex 即可加载新的样式表。
- 安装完成后从桌面或开始菜单打开"Codex 动态壁纸"，先出现的是壁纸管理器，由它启动 Codex。
