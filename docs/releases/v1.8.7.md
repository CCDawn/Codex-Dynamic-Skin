# Codex 动态壁纸 v1.8.7

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.7/docs/releases/v1.8.7-en.md)

这一版把 v1.8.6 修复的问题连根修掉：Codex 26.1117 的顶栏选择器按真实 DOM 重新绑定，顶栏玻璃降为非必需装饰锚点，结构校验不再因为顶栏标记变化而误判。

## 变更

- **顶栏选择器适配 26.1117**：在 26.1117.4957.0 的真实会话页实测确认：`<header>` 元素仍在，但旧的三段兜底（`.app-header-tint`、`data-app-shell-header-edge-scroll`、`_Header_` 模块前缀）全部失配，顶栏只剩 `h-toolbar` 与 `draggable` 两个稳定工具类。合同据此追加新兜底（旧版本继续兼容），选择器合同、双端运行时资产与来源记录一并更新。v1.8.6 从校验器侧容忍了 L0 页面；本版让 26.1117 直接恢复完整 L1 结构，壁纸、顶栏玻璃与所有精修效果全量生效。
- **顶栏玻璃降为非必需装饰锚点**：顶栏玻璃是装饰效果，壁纸与主结构不依赖它。今后 Codex 更新若再令顶栏标记失配，只会降级顶栏玻璃效果，不会再把结构级别拖到 L0、更不会触发校验失败拆除已成功的注入；结构判定以主表面、侧栏等真正必需的锚点为准（#16 教训）。
- **双端同步**：macOS 复用同一份选择器合同（26.1117 的 macOS DOM 未实测，已在来源记录中注明）。

## 不变的部分

- 注入方式仍是仅绑 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名。
- v1.8.6 的启动校验宽容（L0 首页/会话页在 shell、侧栏与页面表面可见时通过）保持不变，两道防线叠加。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。

## 升级与使用

- 已安装 v1.8.0 – v1.8.6 的用户可直接运行新安装包原地升级。
- 升级后在管理器点一次「启动 / 重新应用」即可恢复完整效果。
