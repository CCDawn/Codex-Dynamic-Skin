# Codex 动态壁纸 v1.7.3

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.7.3/docs/releases/v1.7.3-en.md)

本次为品牌统一版本：macOS 侧的应用名称、通知话术与快捷方式全面切换到本仓库品牌「Codex 动态壁纸 / Codex Dynamic Skin」，与 Windows 侧保持一致；功能与 v1.7.2 完全相同，无行为变化。

## 变更

- **应用更名（macOS）**：菜单栏应用显示名从「Codex Dream Skin」改为「Codex Dynamic Skin」；DMG 卷名同步。**从 v1.7.2 及更早升级的用户请注意**：新旧两个应用使用同一内部标识但名称不同，安装新版后请手动把旧的「Codex Dream Skin.app」拖入废纸篓，登录项与设置会自动跟随新版。
- **话术统一（macOS）**：菜单、通知与脚本提示中指官方客户端的「ChatGPT」话术统一为「Codex」；通知标题中残留的「ChatGPT Dream Skin」混合品牌统一为「Codex 动态壁纸」。
- **快捷方式更名（macOS）**：仓库与安装器创建的 5 组 `.command` 快捷方式全部改为新名称；卸载清理同时兼容新旧两代名称，老版本安装的旧快捷方式在卸载时同样会被清掉。
- **文档修正（Windows）**：安装与主题管理文档中的快捷方式名称此前仍为旧名，已对齐实际的「Codex 动态壁纸」。

## 不变的部分

- 内部标识（bundle id、URL 协议、状态目录、DMG 安装包文件名）全部保持不变，升级后设置、登录项与社区主题来源不受影响。
- 独立管理器 `CodexDreamSkinManager.exe` 仅更新版本号，内嵌运行时与 v1.7.2 相同。

## 升级与使用

- 已安装 v1.6.x / v1.7.x 的用户可直接运行新安装包原地升级，已保存的主题、图片与视频壁纸全部保留。
- macOS 用户升级后请删除旧的「Codex Dream Skin.app」（见上文说明），桌面快捷方式会自动替换为新名称。
- 独立管理器（免安装形态）从本仓库 Releases 页面下载 `CodexDreamSkinManager.exe`。
