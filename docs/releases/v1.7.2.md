# Codex 动态壁纸 v1.7.2

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.7.2/docs/releases/v1.7.2-en.md)

本次版本带来选择器兼容档案机制：Codex 客户端界面更新导致皮肤错位时，不再需要等待新版本安装包，维护者发布一份签名档案即可在客户端下次启动时自动修复。

## 新增功能

- **选择器兼容档案（macOS / Windows）**：皮肤依靠选择器定位 Codex 界面元素，官方客户端更新可能让选择器失效。从本版起，客户端启动时异步拉取一份经 ed25519 签名的兼容档案（托管在本仓库 GitHub RAW），校验通过后仅替换内置合同中已登记选择器的定位字符串，任何一步校验失败都整份丢弃、回落内置选择器，绝不影响换肤；拉取超时 5 秒、响应体上限 64 KiB，不新增可执行内容。设置环境变量 `DREAMSKIN_COMPAT_PROFILE=0` 可完全关闭该机制。维护者操作手册见 `docs/compat-profile-runbook.md`。
- **分发通道自主化**：兼容档案与本仓库的版本发布同源（GitHub RAW），不依赖任何第三方服务。

## 修复与改进

- **macOS 更新引导（macOS）**：「检查更新」与更新通知此前会把用户引导到上游原仓库下载；现在全部指向本仓库的 Releases 页面。
- **管理器 EXE 体积（Windows）**：独立管理器 `CodexDreamSkinManager.exe` 不再内嵌它从不运行的原生主题管理器，体积从约 172 MiB 降至约 102 MiB；功能不变，壁纸库、视频预览与 Wallpaper Engine 集成保留。
- **公开预设来源（macOS / Windows）**：内置主题的介绍链接指向本仓库。

## 升级与使用

- 已安装 v1.6.x / v1.7.x 的用户可直接运行新安装包原地升级，已保存的主题、图片与视频壁纸全部保留。
- 兼容档案机制默认开启且无需任何配置；不想参与时设置 `DREAMSKIN_COMPAT_PROFILE=0` 即可（需在启动 Codex 前设置）。
- 独立管理器（免安装形态）从本仓库 Releases 页面下载 `CodexDreamSkinManager.exe`。

## 内部

- 兼容档案七步校验链（固定源、有界读取、结构、版本单调、签名、时效、键交集）在双端共享一个实现（`tools/compat-profile-client.mjs`），由资产同步工具分发到两端，杜绝双端行为漂移。
- 维护者侧签名工具链（`tools/generate-compat-keypair.mjs`、`tools/build-compat-profile.mjs`）与 28 个专项测试用例进入 CI。
- 管理器内嵌清单、release fixture 与 macOS/Windows 字节一致断言全部覆盖新增共享模块，防止再次出现「干净机器缺文件」的发布事故。
- 同步链源文件纳入 `.gitattributes` LF 钉扎，修复 Windows CI 因行尾检出差异误报同步失败的问题。
