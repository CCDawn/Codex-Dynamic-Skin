# Codex 动态壁纸 v1.8.3

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.3/docs/releases/v1.8.3-en.md)

这一版修正安装后的入口：打开应用直接进入壁纸管理器，由管理器启动 Codex；此前入口拉到的是只带主题列表的简易窗口。

## 变更

- **入口改为壁纸管理器**：安装后的快捷方式、开始菜单和安装完成页现在启动 `CodexDreamSkinManager.exe`，即带壁纸库、预览、透明度控制与托盘图标的完整管理器。管理器自身负责准备运行时并拉起 Codex，不再经过安装器脚本的校验流程，因此不会再出现点击后无响应。
- **打包补上管理器**：此前的安装包只包含主题列表窗口，管理器本体没有进入安装目录。现在构建流程会先编译管理器，再把它随安装包一起发布。
- **Wallpaper Engine 场景主题不再报错**：主题媒体类型识别新增 `.pkg` 场景分支。此前以场景壁纸作为当前主题时，脚本初始化会抛出 `Unsupported theme media format: .pkg` 并中止，托盘因此无法驻留。
- **托盘不再依赖独立脚本**：管理器自带托盘图标与右键菜单，启动时默认最小化到托盘，双击恢复窗口。

## 不变的部分

- 注入方式仍是仅绑 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。
- 面板透明度的单层控制、卡片描边与用户消息气泡区分度维持 v1.8.1 的行为。

## 升级与使用

- 已安装 v1.8.0 / v1.8.1 的用户可直接运行新安装包原地升级。
- 安装完成后从开始菜单或桌面打开「Codex 动态壁纸」，即是壁纸管理器窗口。
- 若窗口仍是旧外观，重启一次 Codex 即可加载新的样式表。
