# Codex Dynamic Skin v1.8.2

**English** · [中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.2/docs/releases/v1.8.2.md)

This release fixes the installed entry point: opening the app now goes straight to the wallpaper manager, which then starts Codex. The previous entry point launched a minimal theme list window instead.

## Changes

- **Entry point is the wallpaper manager**: the shortcut, Start menu entry and post-install action now launch `CodexDreamSkinManager.exe`, the full manager with wallpaper library, preview, transparency control and tray icon. The manager provisions the runtime and starts Codex itself, so the shortcut no longer blocks on installer validation.
- **Manager is packaged**: earlier installers only shipped the minimal theme list window and never included the manager binary. The build now compiles the manager and ships it with the installer.
- **Wallpaper Engine scene themes no longer abort**: media type detection now recognises `.pkg` scenes. Previously, with a scene wallpaper active, initialization threw `Unsupported theme media format: .pkg`, which is why the tray never stayed resident.
- **Tray no longer depends on a separate script**: the manager owns its tray icon and context menu, starts minimised to the tray and restores on double click.

## Unchanged

- Injection still uses a loopback-only CDP endpoint on `127.0.0.1`; the official installer and signature are untouched.
- Theme, image and video data directories are unchanged and preserved across upgrades.
- The single-layer panel transparency, card outlines and user message contrast from v1.8.1 are unchanged.

## Upgrade

- v1.8.0 / v1.8.1 users can upgrade in place with the new installer.
- After install, open "Codex 动态壁纸" from the Start menu or desktop; that is the manager window.
- If the window still shows the old appearance, restart Codex once to load the new stylesheet.
