# Codex Dynamic Skin v1.8.5

[中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.5/docs/releases/v1.8.5.md) · **English**

This release does one thing: the composer and the sidebar now share one material, so wallpaper-only mode no longer shows a bright white pane floating in the middle.

## Changes

- **The composer is now dark frosted glass.** In wallpaper-only mode the input field used a bright translucent white fill that clashed with the dark sidebar and looked like an opaque white board over brighter wallpapers. It now uses the same dark base as the sidebar, so the window reads as one theme.
- **The edge stays readable.** With the fill darkened, the composer separates from the wallpaper through a 14% white hairline and a 20px backdrop blur. The 16px corner radius is unchanged and the input area is still obvious at a glance.
- **Shadow matched to the panel layer.** The composer shadow stays at 32% black so switching from a light fill to a dark one does not flatten the layering.

## What stays the same

- Theme, image and video wallpaper data directories are unchanged and survive the upgrade.
- Injection still uses loopback CDP bound to `127.0.0.1` only; the official package and its signature stay untouched and the stock look is always one click away.
- The panel transparency slider still drives the window root, so dragging it changes the whole window at once.

## Upgrading

- Existing v1.8.x installations can run the new package to upgrade in place.
- If the window still shows the old look after upgrading, restart Codex once to load the new stylesheet.
- After installation, open "Codex 动态壁纸" from the desktop or Start menu: the wallpaper manager appears first and launches Codex from there.
