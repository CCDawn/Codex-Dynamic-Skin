# Codex 动态壁纸 v1.8.0

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.0/docs/releases/v1.8.0-en.md)

本次为 Codex 新版兼容与「壁纸独占模式」版本：全面适配 2026 年 11 月连更的 Codex 26.1103 / 26.1106，壁纸独占模式成为默认形态，管理器新增面板透明度滑杆并修复高 DPI 布局。

## 变更

- **Codex 26.1103 / 26.1106 兼容（Windows）**：三处断点全部打通——renderer CSP 不放行回环媒体流，注入时提前放行并对已加载页面刷新一次；MSE 分片段组装被新版拒绝，改为直连视频流渐进播放；官方 CSS Module 类名全族去下划线（主内容、输入框、渐变装饰层），选择器合同改子串匹配并记录实测证据。升级 Codex 后失效的主题与动态壁纸全部恢复。
- **壁纸独占模式成为默认**：默认只透明化表面露出壁纸，配色、字体、布局 100% 保持 Codex 官方样式；需要完整主题皮肤时仍可切换回 full 模式。macOS Studio 自定义主题默认仍为完整皮肤，可用 `--ui wallpaper-only` 指定独占模式。
- **面板透明度滑杆（Windows 管理器）**：会话区卡片（输入框、提示横幅）的磨玻璃透明度独立可调，与壁纸浓度滑杆互不影响；同时清除了会话区上下渐变「雾带」与输入框圆角处的方形尖角问题。
- **默认不再捆绑示例人像**：默认主题改为全透明空白——未选择壁纸时界面保持官方原样；视频流主题在启动加载页恢复 Codex 官方加载页。原示例图仅保留为安装器内的公共预设。
- **管理器界面修复（Windows）**：按显示器 DPI（PerMonitorV2）自适应缩放与布局；Wallpaper Engine 场景流改由管理器本机伺服，不再依赖调试端口。

## 不变的部分

- 注入方式仍是仅绑定 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名，随时可恢复官方外观。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。

## 升级与使用

- 已安装 v1.6.x / v1.7.x 的用户可直接运行新安装包原地升级。
- 升级 Codex 到 26.1103 / 26.1106 后主题失效的用户，安装本版后点击托盘或管理器的「启动 / 重新应用」即可恢复，无需重装 Codex。
- 独立管理器（免安装形态）从本仓库 Releases 页面下载 `CodexDreamSkinManager.exe`。
