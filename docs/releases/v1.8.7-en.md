# Codex Dynamic Skin v1.8.7

**English** · [中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.7/docs/releases/v1.8.7.md)

This release fixes the root cause behind the v1.8.6 workaround: the top-bar selector is re-bound from the real Codex 26.1117 DOM, and the top-bar glass becomes an optional decorative anchor, so structural verification no longer misfires when the top-bar marker changes.

## Changes

- **Top-bar selector adapted to 26.1117**: verified on a live 26.1117.4957.0 session page — the `<header>` element survives, but every legacy fallback (`.app-header-tint`, `data-app-shell-header-edge-scroll`, the `_Header_` module prefix) misses, leaving only the stable `h-toolbar` and `draggable` utility classes. The contract appends the new fallbacks (legacy versions stay compatible); the selector contract, both platforms' runtime assets, and the provenance record are updated together. v1.8.6 tolerated L0 pages at the verifier; this release restores the full L1 structure on 26.1117, so the wallpaper, the top-bar glass, and every refinement apply in full.
- **Top-bar glass demoted to an optional decorative anchor**: the glass is decoration — the wallpaper and the main structure never depend on it. If a future Codex update drops the top-bar marker again, only the top-bar glass degrades; the scope level no longer falls to L0, and a successful injection is never torn down over it. Structural gating now rests on the truly required anchors such as the main surface and the sidebar (the #16 lesson).
- **Both platforms in sync**: macOS reuses the same selector contract (the macOS 26.1117 DOM was not live-tested; noted in the provenance record).

## Unchanged

- Injection still binds only to `127.0.0.1` loopback CDP; the official install and signatures are untouched.
- The v1.8.6 start-verification tolerance (L0 Home and thread pages pass while the shell, sidebar, and a page surface are visible) stays in place — the two defenses stack.
- Local data directories for themes, images, and video wallpapers are unchanged and survive the upgrade.

## Upgrade

- Users on v1.8.0 – v1.8.6 can upgrade in place with the new installer.
- After upgrading, click "Start / Re-apply" once in the manager to restore the full effect.
