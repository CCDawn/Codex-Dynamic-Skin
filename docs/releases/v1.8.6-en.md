# Codex Dynamic Skin v1.8.6
[中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.6/docs/releases/v1.8.6.md) · **English**

This release fixes the start path: on Codex 26.11xx, pressing Start reported Dream Skin verification failed and closed the window. It now starts.

## Changes

- **Accept L0 Home and thread pages**: Codex 26.11xx no longer emits the header tint marker on those pages, which drops the structure level from L1 to L0. The previous check only accepted "L0 + settings" and "complete L1", so Home and thread pages fell in between and every start failed. Any L0 page with a visible sidebar and main surface now passes; pages missing either anchor still fail closed.
- **Fix the one-pixel edge misjudgement**: after rounding, a region's right or bottom edge could land exactly one pixel outside the viewport, which then failed the composer visibility check. The right and bottom edges now allow a one-pixel rounding tolerance while the left and top edges stay strict.
- **Windows and macOS together**: both platforms share the same L0 structure rule, so one side cannot silently stay broken.

## Unchanged

- Injection still uses a loopback-only CDP endpoint on `127.0.0.1`; the official installer and signature are untouched and the stock appearance can be restored at any time.
- Theme, image, and video wallpaper data directories are unchanged and survive the upgrade.
- The panel transparency slider, wallpaper reveal slider, and scene wallpaper behaviour are unchanged.

## Upgrade and usage

- v1.8.x users can run the new installer in place.
- If the window still shows the old appearance, restart Codex once to load the new stylesheet.
- After installation, open "Codex 动态壁纸" from the desktop or Start menu; the wallpaper manager appears first and starts Codex from there.
