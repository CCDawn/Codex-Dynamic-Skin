## Codex 动态壁纸 v1.6.0

本次为本仓库合并上游 [Codex Dream Skin v1.5.18](https://github.com/Fei-Away/Codex-Dream-Skin) 后的首个版本，视频壁纸能力在新引擎上完整保留。

### 主要变更 / 本次变更

- **兼容 2026 年 9 月版 Codex（26.915）**：引入上游选择器合同引擎，`selectors.json` 三重兜底选择器 + 社区兼容性档案，彻底解决 9 月初 Codex DOM 改版导致的皮肤失效。
- **视频壁纸完整保留**：本地 MP4/WebM 动态壁纸、分块 CDP 传输、壁纸透出滑杆、页面隐藏暂停等能力全部迁移到新渲染架构；社区主题 ZIP、Safe CSS 校验、中英文托盘等上游新特性同时可用。
- **Wallpaper Engine 回退**：创意工坊目录缺失或引用失效时自动回退主题目录托管副本，不再启动失败。
- **品牌统一为「Codex 动态壁纸」**：托盘、安装向导、快捷方式、更新提示全部改用本仓库品牌；更新检查指向本仓库 releases。
- **受管 CDP 配置**：与官方 Codex 配置隔离，首次使用需在皮肤会话中重新登录一次，之后保持登录。

### 升级说明 / 升级说明

- 已安装上游 v1.5.18 的用户可直接运行本安装包原地升级，旧英文快捷方式会自动清理，已保存主题与图片保留。
- 从 v1.1.0（管理器 EXE）升级的用户：可直接安装本安装包，也可继续使用随后发布的新版管理器 EXE。
