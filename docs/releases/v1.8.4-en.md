# Codex Dynamic Skin v1.8.4

**English** · [中文](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.4/docs/releases/v1.8.4.md)

This release fixes upgrades getting stuck on scene wallpapers: when the active theme is a Wallpaper Engine scene (including the legacy declaration form), install and start no longer fail by mistaking it for an image.

## Changes

- **Scene themes no longer block install and start**: when the active theme is a Wallpaper Engine scene (`scene.pkg`, including the legacy declaration form), the install and start paths previously failed image validation against it, causing the install to roll back and the app to fail to start. These themes are now read and tolerated as scene media, so upgrades are no longer stuck on old scene themes.
- **Startup validation failures degrade to warnings**: a theme validation failure at startup no longer aborts startup; it is downgraded to a warning and the current injection state is preserved.

## Unchanged

- Injection still uses a loopback-only CDP endpoint on `127.0.0.1`; the official installer and signature are untouched.
- No selector or compatibility changes in this release, and no functional changes on macOS.
- Theme, image and video data directories are unchanged and preserved across upgrades.

## Upgrade

- v1.8.0 – v1.8.3 users can upgrade in place with the new installer.
- If a theme displays incorrectly after the upgrade, re-apply it once in the manager to restore it.
