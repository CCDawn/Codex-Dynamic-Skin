# Codex 动态壁纸 v1.8.1
**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.1/docs/releases/v1.8.1-en.md)

这次是壁纸独占模式的收尾修复：面板透明度真正由滑杆单层控制，界面各处不再出现「一半透明一半实心」的分界，Windows 启动也不再闪出两个 Codex 窗口。

## 变更

- **面板透明度改为单层控制**：此前主内容区、侧栏、输入框卡片各自带一层半透明底色，叠在一起最浓处接近 0.93，壁纸几乎透不出来，滑杆拖到哪都看不出差别。现在只有窗口根节点保留一层底色，其余表面全部让位，拖动滑杆时整窗同步变化。
- **透明度滑杆不再被弹回**：管理器在没有保存记录时会强制把滑杆拉回 30，而 30 对应的浓度恰好和默认值一致，看起来就像「怎么调都没反应」。现在只有真实保存过的值才会回写滑杆，拖动立即生效，无需重启 Codex。
- **侧栏与图标栏统一**：左侧图标栏、会话导航栏、主内容区之前各自保留白色底，在全透明界面上会露出几条孤立的白带；现在与主面板共用同一层浓度。
- **对话卡片与输入框保留边界**：底色清空后，卡片原本靠 0.5 像素阴影环表现的边界会消失。现在卡片、输入框、资源面板改用固定的浅色底加一条细边线，既跟随壁纸又能分辨层级；输入框同时恢复 16 像素圆角。
- **用户消息气泡独立可见**：用户消息保留固定的浅灰底与描边，不再因为整体透明化而和助手内容混成一片。
- **单窗口启动**：此前每次启动会先走包激活拉起一个 Codex，检测到调试参数被改写后关闭它，再启动真正的实例，过程中必然闪出两个窗口。现在直接启动已验证的 Store 可执行文件，只出一个窗口。
- **启动失败分类保留**：直连启动被拒绝时仍区分为访问受限、参数丢失、端点不可用三类，并在参数丢失时只关闭本次启动的进程，不影响此前已在运行的 Codex。

## 不变的部分

- 注入方式仍是仅绑 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名，随时可恢复官方外观。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。
- macOS 侧行为未改动，版本号随发布同步。

## 升级与使用

- 已安装 v1.6.x / v1.7.x / v1.8.0 的用户可直接运行新安装包原地升级。
- 升级后如果窗口仍是旧外观，重启一次 Codex 即可加载新的样式表。
- 面板透明度滑杆在管理器窗口内，拖动后立即生效；壁纸浓度滑杆仍独立控制壁纸本身的透出程度。
