# Codex 动态壁纸 v1.8.8

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.8.8/docs/releases/v1.8.8-en.md)

这一版修掉 Codex 26.1117 右侧浮动停靠（侧边对话）面板不透出壁纸的问题：该面板的外壳用一段皮肤从未覆盖过的 Tailwind 任意值类画不透明底色，壁纸独占模式下整块读成原生深色板；现在它与主线程一样透出壁纸，同时保留左边框与文字可读性。

## 变更

- **停靠面板透出壁纸（壁纸独占模式）**：在 26.1117.4957.0 实机只读 DOM 实测定位根因——右侧浮动停靠面板区域唯一的不透明绘制元素是类含 `bg-[var(--app-shell-panel-background,var(--color-surface))]` 的容器 DIV；它既不含 `bg-surface` 令牌也没有 CSS Module 名，皮肤已有的表面清除规则（令牌族与兜底规则）全部匹配不到它。新增规则按外壳自带的 `app-shell-panel-background` 令牌片段（稳定语义片段，非 hash）清除其底色；面板左边框在祖先元素上、文字令牌保持原生，均不受影响。
- **full 主题模式同步上材质**：同一面板在 full 模式下改用主题面板材质（`--ds-panel-rgb` / 面板透明度滑块链），与输入框、弹窗的既有做法一致；交互控件与浮层容器保留自身绘制。
- **选择器合同新增 `floating-dock` 锚点**（L2 非必需）：停靠面板仅在开启侧边对话时出现，缺失只降级诊断、不影响结构判定；CSS 经同一锚点令牌消费，合同来源记录（verifiedAgainst）随本次实机证据一并更新。旧版 Codex 不渲染该类，规则自然不生效，也不会误伤 `bg-surface` 令牌族的元素。
- **双端同步**：macOS 复用同一份 CSS 与合同（macOS 的停靠面板 DOM 未实测，已在来源记录中注明）。

## 不变的部分

- 注入方式仍是仅绑 `127.0.0.1` 的本机 CDP，不修改官方安装包与签名。
- 壁纸独占模式的整体合同不变：`#root` 上唯一一层磨砂，面板、卡片照旧透明，弹窗/菜单照旧保持近实底可读。
- 主题、图片与视频壁纸的本机数据目录不变，升级后全部保留。

## 升级与使用

- 已安装 v1.8.0 – v1.8.7 的用户可直接运行新安装包原地升级。
- 升级后在管理器点一次「启动 / 重新应用」即可恢复完整效果；已打开的侧边对话面板会随新 CSS 生效。
