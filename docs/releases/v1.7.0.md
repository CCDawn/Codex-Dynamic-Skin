# Codex 动态壁纸 v1.7.0

**中文** · [English](https://github.com/CCDawn/Codex-Dynamic-Skin/blob/v1.7.0/docs/releases/v1.7.0-en.md)

本次为本仓库合并上游 Codex Dream Skin v1.5.19–v1.5.20 后的首个版本，兼容性与功能双吸收：Codex 26.930 兼容、主题透明度控制、原生主题管理器与 CODEX_HOME 自定义目录支持全部进入本仓库，视频壁纸、RDP 静态帧降级与「Codex 动态壁纸」品牌保持不变。

## 新增功能

- **Codex 26.930 兼容（macOS / Windows）**：页面枚举按活动页过滤，跳过新版路由下的缓存页面（`[data-app-shell-active-page=false]`），修复锚点误选导致皮肤应用到错误页面的问题；同时适配 26.930 的缓存页面、标题栏、工具页面、代码块与展开表格（上游 v1.5.19 变更，逐条见平台 CHANGELOG）。
- **主题透明度控制（macOS / Windows）**：背景透明度遵循「用户设置 > 主题作者显式 alpha > 默认 30%」。macOS 主题菜单新增按主题保存的透明度滑块与「跟随主题」；Windows 在原生主题管理窗口提供同样的按主题偏好。
- **原生主题管理器（Windows）**：双击桌面快捷方式、开始菜单项或托盘图标，统一打开 C# 原生主题管理窗口：按主题调整 0–100% 透明度、恢复「跟随主题」，未使用的主题确认后移入回收站删除；使用中的主题需先经托盘切换。原 PowerShell 主题选择窗口已移除。
- **CODEX_HOME 自定义配置目录（Windows）**：安装、启动和恢复遵循已有的 `CODEX_HOME`，未设置或为空时使用默认 `.codex` 目录；备份绑定来源目录、拒绝跨目录恢复，无效路径明确报错。

## 修复与改进

- **管理器 EXE 启动/恢复失败（Windows）**：v1.6.2 管理器 EXE 的内嵌运行时缺少 4 个文件，干净机器上「启动」「恢复」会失败。Manager EXE 资产已在 v1.6.2 上热修复；本版起内嵌清单有契约测试守护，不会再缺文件发布。
- **渲染性能（macOS / Windows）**：缓存皮肤 CSS 的结构判断，页面结构变化时批量更新，减少滚动和页面切换时的整页样式重算。

## 升级与使用

- 已安装 v1.6.x 的用户可直接运行新安装包原地升级，已保存的主题、图片与视频壁纸全部保留。
- Windows 使用自定义 `CODEX_HOME` 时，安装器、托盘与官方 Codex 必须读取到同一个已有的用户级环境变量；仅在终端设置可能无法传给通过 Microsoft Store 激活的应用，必要时注销 Windows 后重新登录。已有备份时，请先在原目录完成恢复，再切换到新目录。
- 想试用原生主题管理器的 Windows 用户：双击桌面「Codex 动态壁纸」快捷方式或托盘图标即可打开；macOS 用户在主题菜单里使用透明度滑块与「删除已保存主题」。

## 内部

- 合并上游 Codex Dream Skin v1.5.19–v1.5.20 全部改动；fork 的视频壁纸、RDP 静态帧降级与品牌完整保留。
- CI 版本一致性闸门覆盖第七处版本源（管理器 csproj），七处版本号必须一致才能合并与发版。
- 发布说明规范化：每次发版维护中英两份说明（见 docs/releases/README.md），发版工作流在发布前校验两份文件非空。
